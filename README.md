# Customer Experience & Sales Analytics Pipeline

Un pipeline de datos end-to-end para análisis de Customer Experience (CX) y métricas de ventas en Retail.

## 🔗 Dashboard Interactivo
Puedes acceder y explorar el reporte en vivo directamente en Looker Studio:
👉 **[Ver Dashboard Interactivo en Looker Studio](https://datastudio.google.com/reporting/6efce536-fdf8-47b7-949c-c243d8ab74fc)**

## 🛠️ Tecnologías Utilizadas
- **Database:** PostgreSQL (Modelado relacional y vistas agregadas)
- **Lenguaje:** Python 3.10 (Pandas para ETL automatizado)
- **Visualización:** Looker Studio
- **Control de Versiones:** Git & GitHub

## 📊 KPIs Clave
- **Ventas Totales:** $495.50
- **Tiempo Promedio de Respuesta:** 20.7 min
- **Tasa de Resolución:** 66.7%

## 📂 Estructura del Repositorio
- `data/`: Datasets limpios e insumos.
- `sql/`: Scripts de tablas, relaciones y vistas relacionales.
- `scripts/`: Scripts automatizados en Python para extracción y procesamiento.
- `dashboard/`: Capturas y recursos visuales del reporte interactivo.
