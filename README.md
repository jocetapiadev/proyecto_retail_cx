# Customer Experience & Sales Analytics Pipeline

Un pipeline de datos end-to-end para análisis de Customer Experience (CX) y métricas de ventas en Retail.

## 🛠️ Tecnologías
- **Database:** PostgreSQL (Modelado relacional y vistas agregadas)
- **Lenguaje:** Python 3.10 (Pandas y ETL automatizado)
- **Visualización:** Looker Studio
- **Control de Versiones:** Git & GitHub

## 📊 KPIs Clave
- **Ventas Totales:** $495.50
- **Tiempo Promedio de Respuesta:** 20.7 min
- **Tasa de Resolución:** 66.7%

## 📂 Estructura
- `data/`: Dataset procesado final.
- `sql/`: DDL y vistas PostgreSQL.
- `scripts/`: Script de procesamiento ETL en Python.
- `dashboard/`: Capturas y recursos del reporte en Looker Studio.
